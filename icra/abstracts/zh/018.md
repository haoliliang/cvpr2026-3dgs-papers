### [18] GGD-SLAM: Monocular 3DGS SLAM Powered by Generalizable Motion Model for Dynamic Environments
- **arXiv:** [2604.12837](https://arxiv.org/abs/2604.12837)

Visual SLAM 算法通过探索 3D Gaussian Splatting（3DGS）表示取得了显著改进，尤其在生成高保真稠密地图方面。然而，它们依赖静态环境假设，在动态环境中性能显著下降。本文提出 GGD-SLAM，一种采用 generalizable motion model 应对动态环境中定位与稠密建图挑战的框架——无需预定义语义标注或深度输入。具体而言，所提系统采用 First-In-First-Out（FIFO）队列管理 incoming frames，通过 sequential attention 机制促进 dynamic semantic feature extraction。这与 dynamic feature enhancer 集成以分离静态与动态分量。此外，为最小化 dynamic distractors 对静态分量的影响，我们设计通过 static information sampling 填充遮挡区域的方法，并针对动态环境设计 distractor-adaptive Structure Similarity Index Measure（SSIM）loss，显著增强系统 resilience。在真实世界动态数据集上的实验表明，所提系统在动态场景的相机位姿估计与稠密重建方面达到 state-of-the-art 性能。
